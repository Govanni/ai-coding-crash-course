# Starting point: basic TypeScript, no React, fuzzy client/server, no databases

Self-reported at session 1 (2026-11-10). The user knows basic TypeScript syntax and has done a little vibe coding. They have never used React, are unclear on the client/server split, and have no database knowledge. The goal is to follow the AI Coding Crash Course on the Cadence repo.

**Implications:** Don't re-teach TS types or syntax. Every lesson should say where code runs (browser, server or db). Teach React only as far as reading Cadence's components requires. Databases start from zero (tables, rows, columns, then joins, then migrations), but only after the request journey (lesson 0001) is solid.
