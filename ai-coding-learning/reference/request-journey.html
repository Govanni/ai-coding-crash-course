Anatomy of a route file

server only
export async function loader({ request, url, params }) {
  // read the URL, call services, return plain data
  return { courses };
}

server + browser
export default function Page({ loaderData }) {
  const { courses } = loaderData;   // ← same shape the loader returned
  return <div>{courses.map(c => <p>{c.title}</p>)}</div>;
}

Rules of thumb

  • Components never touch the database. They only see loaderData.
  • console.log in a loader shows in the terminal. In a component it shows in both places on a full reload, and only in the browser on in-app navigation.
  • Setup for a fresh clone: npm run db:migrate → npm run db:seed → npm run dev.
